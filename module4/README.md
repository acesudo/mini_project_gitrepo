# Module 4 — Face Recognition & FaceNet Embeddings

## 1. Overview

Module 4 is responsible for **facial representation learning**. It converts preprocessed face images into **512-dimensional numerical vectors (embeddings)** using a pretrained **FaceNet (Inception-ResNet-v1)** deep convolutional neural network in PyTorch.

In our Face Attendance system, raw pixel images are never compared directly because differences in lighting, facial expressions, and minor head tilts cause massive variations in raw pixel values. Instead, FaceNet extracts high-level semantic facial features (eye spacing, jawline contours, nose-bridge geometry) into a compact numerical signature.

``` mermaid
flowchart LR
    A[Preprocessed Face<br/>160x160x3 RGB] --> B[Fixed Standardization<br/>(x - 127.5)/128.0]
    B --> C[FaceNet Inception-ResNet-v1<br/>Pretrained on VGGFace2]
    C --> D[Raw Output Tensor<br/>Shape: 512]
    D --> E[L2 Normalization<br/>||v||_2 = 1.0]
    E --> F[Face Embedding Vector<br/>512 float32]
```

## 2. Deep Learning Concepts for Students

### What is a Face Embedding?
An embedding is a low-dimensional numerical vector representing complex, high-dimensional data (like an image). In FaceNet, every face image is projected onto a point on a **512-dimensional unit hypersphere**.
- Faces of the **same student** produce vectors that lie **close together** (small Euclidean distance, high cosine similarity).
- Faces of **different individuals** produce vectors that lie **far apart**.

### Why L2 Normalization is Critical
Every embedding vector $v$ generated by `FaceEmbeddingGenerator` is divided by its Euclidean norm ($L_2$ norm):
$$\hat{v} = \frac{v}{\|v\|_2} = \frac{v}{\sqrt{\sum_{i=1}^{512} v_i^2}}$$

When vectors have unit length ($\|u\|_2 = 1$ and $\|v\|_2 = 1$), their squared Euclidean distance directly correlates with cosine similarity:
$$\|u - v\|^2 = \|u\|^2 + \|v\|^2 - 2(u \cdot v) = 2 - 2\cos(\theta)$$

This mathematical equivalence simplifies the thresholding and face-matching logic in **Module 5**.

### Multi-Sample Student Representation
During student registration (Module 3), 5 facial samples are captured under slightly different angles. Rather than storing 5 separate embeddings or arbitrarily picking one, Module 4 computes the **centroid (mean embedding)** across all samples:
$$v_{\text{student}} = \text{normalize}\left( \frac{1}{N} \sum_{k=1}^N e_k \right)$$

This filters out transient noise (such as blinking or shadows) and creates a robust template for attendance marking.

## 4. Key Classes & Methods

### `FaceEmbeddingGenerator`

Located in `module4/face_embedding.py`:

| Method | Parameters | Return Type | Description |
|---|---|---|---|
| `__init__` | `model_name="vggface2"`, `device=None` | `None` | Loads pretrained FaceNet onto GPU or CPU in `.eval()` mode. |
| `preprocess_image` | `face_image: np.ndarray` | `torch.Tensor` | Validates `(160, 160, 3)` RGB array and applies `(x - 127.5) / 128.0`. |
| `generate_embedding` | `face_image: np.ndarray` | `np.ndarray` | Generates 512-dimensional $L_2$-normalized `float32` vector. |
| `generate_embeddings_batch` | `face_images: list[np.ndarray]` | `list[np.ndarray]` | Batch inference for multiple faces in a single frame. |
| `generate_student_representation` | `face_images: list[np.ndarray]` | `np.ndarray` | Averages sample embeddings and normalizes the centroid. |
| `embedding_to_bytes` | `embedding: np.ndarray` | `bytes` | Serializes 512 floats into 2,048 bytes for database storage. |
| `bytes_to_embedding` | `data: bytes` | `np.ndarray` | Deserializes raw bytes back into `(512,)` float32 array. |
| `embedding_to_list` | `embedding: np.ndarray` | `list[float]` | Converts embedding to Python float list for JSON APIs. |
| `list_to_embedding` | `data: list[float]` | `np.ndarray` | Reconstructs numpy vector from list of floats. |

## 8. Common Errors & Troubleshooting

1. **`ValueError: Expected face_image of shape (160, 160, 3)`**
   - *Cause:* Input face crop has not been resized or is grayscale.
   - *Fix:* Always pass images through `module3.face_preprocessing.preprocess_face()`.

2. **`ModuleNotFoundError: No module named 'facenet_pytorch'`**
   - *Cause:* The package is not installed in `.venv`.
   - *Fix:* Run `.\.venv\Scripts\pip install --no-deps facenet-pytorch`.

3. **`SSL: UNEXPECTED_EOF_WHILE_READING` during first model initialization**
   - *Cause:* Python's default urllib occasionally drops connections during the initial weights download from GitHub Releases.
   - *Fix:* Weights are cached locally at `~/.cache/torch/checkpoints/20180402-114759-vggface2.pt` (111.9 MB). Once downloaded, FaceNet loads entirely offline without network access.
